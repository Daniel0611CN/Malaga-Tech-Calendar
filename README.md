# Málaga Tech Calendar

Agenda visual y responsive para descubrir eventos tecnológicos de Málaga y la Costa del Sol.

## Stack

- React + TypeScript
- Vite
- CSS responsive con dark mode / light mode
- Lucide React para iconografía

## Desarrollo local

```bash
npm install
npm run dev
```

Para validar la aplicación:

```bash
npm run lint
npm run build
```

La aplicación incluye eventos de ejemplo, búsqueda, filtros por categoría, tarjetas de eventos con detalle modal y cambio de tema.
